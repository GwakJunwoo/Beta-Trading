# 채권 3팩터 전략 — 산식과 신호 로직

> 본 문서는 RV · MOM · CURVE 세 팩터의 **산식과 신호 산출 로직**을 정리한 내부 자료다.
> 이론적 직관, 수식, 매매 진입 방식 위주로 서술하며, 백테스트 결과·검증 통계는 별도 명세서(`bond_3factor_final_spec.md`)를 참고한다.

---

## 0. 전체 구조

세 팩터는 모두 한국 국고채(KTB) 시장의 **금리 변동 메커니즘**에서 추출된다.
어떤 팩터든 출발점은 같은 회귀식 하나다.

```
dY_i,t = α_i + β_3Y,i · dY_3Y,t + β_10Y,i · dY_10Y,t + ε_i,t
```

여기서 좌변은 종목 i의 일일 yield 변화(bp)이고, 우변은 두 가지 부분으로 나뉜다.
**β_3Y · dY_3Y + β_10Y · dY_10Y** 는 모든 채권이 함께 노출되는 **시장 공통 risk** (3년 지표·10년 지표 두 시장 변수에 대한 노출)이고,
**ε_i,t** 는 그 종목만의 **고유 잔차** — 시장 평균으로 설명되지 않는 독자 변동이다.

이 한 식에서 세 팩터를 추출한다:

- **RV** — 잔차 ε 자체를 누적해서 종목 간 상대 가격을 비교
- **MOM** — 시장 공통 변수 dY_3Y 의 누적 추세를 따라가는 베팅
- **CURVE** — dY_10Y 와 dY_3Y 의 차이(슬로프) 변화의 평균회귀에 베팅

세 팩터는 같은 회귀에서 나오지만 서로 다른 정보를 사용하기 때문에 구조적으로 직교에 가깝다.
이게 합성했을 때 risk 분산 효과가 나는 근거가 된다.

---

## 1. 공통 토대 — 2팩터 회귀

세 팩터의 모든 계산은 매일, 모든 KTB 종목에 대해 위 회귀식을 푸는 데서 시작한다.
회귀는 **3M rolling OLS** 방식으로 돌리며, 매일 직전 63영업일의 데이터로 β 두 개와 잔차 ε 를 갱신한다.

각 종목의 β 추정치는 만기에 따라 자연스러운 패턴을 보인다.
3년 지표 종목 자체로 회귀를 돌리면 β_3Y ≈ 1, β_10Y ≈ 0 이 나오고,
10년 지표 종목은 β_10Y ≈ 1, β_3Y ≈ 0 이 나오며,
중기물(5년 잔존 정도)은 두 β 값이 0.3 ~ 0.7 범위로 절반씩 노출된다.
이 sanity check 결과가 회귀 구조 자체의 정합성을 입증한다.

회귀는 지표 롤오버일 ±5영업일을 제외해 데이터 점프 영향을 차단한다.
그렇게 추출한 잔차 ε 의 평균 표준편차는 약 1.15 bp/일 수준으로,
원본 dY_i 표준편차(약 5 bp/일)의 약 1/5에 불과하다.
즉 **2팩터로 일간 금리 변동의 87% 가량이 설명되고**, 남은 13% 정도가 RV 팩터의 재료다.

## 2. RV 팩터 — 잔차의 누적 평균회귀

### 직관

어떤 채권의 yield가 같은 시장 변수에 의해 설명되는 것보다 **더 많이** 올랐다면
(즉 ε가 양수로 누적되었다면), 그 채권은 **상대적으로 싸진** 상태다.
시장이 이 갭을 인식하면 mean reversion이 일어나면서 yield가 일부 되돌아 오고 가격이 회복된다.
반대로 ε가 음수로 누적된 채권은 **상대적으로 비싸진** 상태이므로 SHORT 포지션 후보다.

### 산식

먼저 일별 잔차를 일정 기간 동안 누적해 RV score 를 만든다:

```
RV_i,t = Σ(s=t-20 → t) ε_i,s        (단위: bp)
```

윈도우는 21영업일(약 1개월)이 주력이다. 이보다 짧으면 노이즈 우세이고 더 길면 신호가 희석된다.

RV_i,t > 0 이면 종목 i가 상대적으로 cheap 한 상태이고, RV_i,t < 0 이면 rich 한 상태다.

### 신호 산출 로직 — Within-bucket Quintile

RV score 를 그대로 cross-section에서 줄세우면 한 가지 큰 함정이 있다.
KTB 유니버스의 잔존만기는 0.5년에서 50년까지 매우 wide한데,
같은 RV bp 값이라도 만기에 따라 의미가 다르다.
장기물은 자연스럽게 잔차의 절대값이 크고 단기물은 작기 때문에,
단순 quintile은 **RV 신호와 만기 sorting을 섞어버린다**.

이 문제를 해결하기 위해 종목을 먼저 만기 버킷으로 나눈다:

```
≤ 5년     (단기물)
5 ~ 10년  (중기물)
> 10년    (장기물)
```

각 버킷 안에서 따로 RV score 기준 quintile (Q1 ~ Q5) 을 매긴 다음,
세 버킷의 라벨을 통합해 전체 풀의 quintile 분포를 얻는다.
이렇게 하면 quintile은 만기 효과를 통제한 상태에서 **순수한 cross-section RV 강도**만 잡는다.

포지션은 단순하다:

```
LONG  Q5 (가장 cheap한 그룹, 16종목 내외)
SHORT Q1 (가장 rich한 그룹, 14종목 내외)
```

### 운용 디테일

신호의 자연스러운 holding period는 **21영업일**이다.
잔차의 mean reversion이 1개월 정도 시간 척도에서 일어나기 때문이다.
1일 hold로 평가하면 단조성이 깨진다 — 하루 안에 mean revert가 일어나기엔 너무 짧다.

따라서 RV는 **월 1회 rebalance**가 자연스럽고, 그 사이에는 같은 포지션을 유지한다.
이 점이 다른 두 팩터(MOM, CURVE)가 daily 신호인 것과 다르다.

진입 종목은 만기 버킷별로 골고루 나오기 때문에,
실거래 시 LONG 16종목 / SHORT 14종목 전부 포지션을 잡는 대신
각 만기 버킷에서 RV score 가 가장 강한 top N 종목만 선택해 운용하는 게 현실적이다.

## 3. MOM 팩터 — 3M 금리 추세 추종

### 직관

3년 금리가 지난 3개월 동안 한 방향으로 꾸준히 움직였다면,
그 추세가 다음 며칠에서 몇 주 사이에 추가로 지속될 가능성이 있다.
이건 채권 시장의 **단기~중기 momentum**을 잡는 베팅이다.

주식 시장의 momentum 만큼 강력하지는 않지만,
강한 trend regime(강세장 가속, 약세장 가속)에서 분명히 신호가 작동한다.

### 산식

지난 63영업일(약 3개월) 동안의 dY_3Y 누적치가 신호의 출발점이다:

```
cum_dY_3Y,t = Σ(s=t-62 → t) dY_3Y,s          (단위: bp)
            = Y_3Y,t - Y_3Y,t-63             (3개월 yield level 차이)
```

이 누적치의 부호가 추세 방향이고, 그 부호의 반대가 LONG/SHORT 신호다:

```
MOM_signal_t = - sign(cum_dY_3Y,t)            (-1, 0, +1)
```

부호 의미는 다음과 같다:

- cum_dY_3Y > 0 (3개월 동안 rate 상승 추세) → signal = -1 → **3Y bond SHORT**
  rate가 더 오를 거라 베팅하므로 bond SHORT.
- cum_dY_3Y < 0 (3개월 rate 하락 추세) → signal = +1 → **3Y bond LONG**
  rate가 더 내릴 거라 베팅하므로 bond LONG.

### 왜 raw 누적치 부호인가 — z-score를 안 쓰는 이유

원래 명세에는 cum_dY_3Y 를 1년 trailing σ 로 표준화한 z-score 를 쓸 계획이었다.
그런데 실증 분석 결과, **z-score 표준화가 신호의 정보량을 절반 이상 죽인다**.

이유는 직관적이다.
z-score는 vol regime(시장 변동성 수준)을 섞는다.
2022년처럼 vol이 큰 시기에 cum +30bp 는 z=+1 정도지만,
2025년처럼 vol이 작은 시기에 같은 +30bp 는 z=+3 으로 표시된다.
즉 같은 rate 움직임이 시기에 따라 **다른 강도로 인식**되는데,
실제 trend persistence는 vol regime과 큰 상관이 없다.

raw 누적치의 부호만 쓰면 vol regime에 강건하고 해석도 명확하다.
"지난 3개월 rate 올랐냐 떨어졌냐"라는 단순한 binary 정보다.

### 왜 윈도우 63일인가

cumulative window 길이를 다양하게 시험한 결과:

- 1 ~ 5일: 단기 noise → 오히려 mean-reversion 우세 (즉 momentum 가정과 반대)
- 10 ~ 21일: 약한 momentum
- 42일: momentum과 mean-rev 의 경계, 신호 애매
- **63일 (3개월)**: momentum 가장 깨끗
- 126일 이상: 다시 mean-rev 우세 (장기 평균회귀)

3개월이 한국 국고채에서 trend persistence가 가장 잘 잡히는 자연 척도였다.
이 길이는 BOK 정책 cycle 단위와도 어느 정도 부합한다.

### 운용 디테일

매일 cum_dY_3Y 값을 계산해 부호가 바뀌면 포지션을 뒤집는다.
실측해보면 **연 6 ~ 7회** 정도 flip이 발생한다 (평균 보유 36일).

진입 수단은 **3년 지표 종목 단일** (현재 25-10).
단일 종목 매매라 거래비용 부담이 가장 작은 팩터다.
SHORT 포지션은 RP 대차로 진입하므로 대차료(연 5 ~ 30 bp) 가 net P&L에 차감된다.

## 4. CURVE 팩터 — 슬로프 평균회귀

### 직관

10년 금리에서 3년 금리를 뺀 값이 yield curve 의 슬로프다.
한국 국고채 시장에서 **슬로프의 단기 변동은 평균회귀 성향**이 강하다.
지난 3주 사이 슬로프가 계속 가팔라졌다면(steepen), 곧 평탄화(flatten) 쪽으로 되돌아오는 경향이 있고, 반대도 마찬가지다.

이 mean reversion 은 시장 참가자들이 슬로프 과열을 인지하고 반대 포지션을 취하면서 일어난다.
또한 BOK 정책 cycle 변화 등 macro 충격 후 일시적 dislocation 이 일어났다가 정상화하는 패턴도 포함한다.

### 산식

먼저 일별 슬로프 변화를 정의한다:

```
slope_t = dY_10Y,t - dY_3Y,t                  (단위: bp/일)
```

이건 그날 하루 동안 슬로프가 얼마나 가팔라졌는지(양수) 평탄해졌는지(음수) 를 나타내는 값이다.

그 다음 21영업일(약 3주) 누적치를 신호로 삼는다:

```
cum_slope_t = Σ(s=t-20 → t) slope_s           (3주 누적)
```

cum_slope 가 양수면 지난 3주 슬로프가 계속 steepen 되었음을 뜻한다.
mean reversion 가정 하에 다음에는 flatten 쪽으로 되돌아올 것을 기대한다:

```
CURVE_signal_t = - sign(cum_slope_t)          (-1, 0, +1)
```

신호 의미:

- cum_slope > 0 (지난 3주 steepen 누적) → signal = -1 → **FLATTEN 베팅**
  3Y SHORT / 10Y LONG (duration-neutral 페어). 슬로프가 좁혀지면 이익.
- cum_slope < 0 (지난 3주 flatten 누적) → signal = +1 → **STEEPEN 베팅**
  3Y LONG / 10Y SHORT (duration-neutral 페어). 슬로프가 벌어지면 이익.

### 명세에 없던 두 가지 단순화

원래 명세는 두 단계 과정을 거쳤다.
첫째, slope 자체를 dY_3Y 에 회귀해 잔차 u_t 를 추출 (MOM과 직교화).
둘째, u_t 를 21d window로 z-score 변환.

실증 분석 후 **두 단계 모두 제거**했다.

먼저 직교화 단계는 효과가 없었다.
slope ~ dY_3Y rolling OLS 의 β 평균이 -0.078 (거의 0) 이었다 —
즉 slope과 dY_3Y 사이에 의미 있는 선형 관계가 애초에 없으므로,
회귀를 거쳐도 신호가 거의 그대로다.
오히려 rolling OLS의 window noise만 추가되어 성능이 약간 떨어졌다.

둘째, z-score 단계는 MOM과 같은 이유로 정보를 죽였다.
vol regime을 섞으면서 신호가 희석된다.

따라서 현재 확정안은 **raw cum_slope 의 부호** 를 그대로 사용한다.

### 왜 윈도우 21일인가

lookback × forward IC 그리드를 검증해 본 결과:

- 1 ~ 5일: 약한 mean-rev
- 10 ~ 21일: mean-rev 강해짐
- **21일**: lookback / forward IC 가장 깨끗 (절대값 0.26 ~ 0.43)
- 42 ~ 63일: 더 길어도 큰 개선 없음, hold 부담만 증가

3주(21영업일) 가 한국 슬로프 mean reversion의 자연 시간 척도였다.

### 운용 디테일

매일 cum_slope 부호 확인 후 페어 포지션을 갱신한다.
**flip 빈도가 매우 높다 — 연 30 ~ 35회**.
이는 슬로프 자체의 변동성이 작고 0 근처를 자주 교차하기 때문이다.

진입 수단은 **3년 지표 + 10년 지표 duration-neutral 페어**.
페어의 비중은 BPV 비율로 정한다.
대략 10년 1단위에 대해 3년을 3 ~ 4배 더 매수/매도한다.

페어 트레이드라 한 번 flip 시 양 leg 모두 round-trip 거래가 발생한다.
다른 두 팩터(RV, MOM)에 비해 거래비용 부담이 압도적으로 크다.
이 점은 단독 운용 시 net P&L 에 큰 영향을 미치므로 합성 운용이 권장된다.

## 5. 세 팩터의 관계

세 팩터가 같은 회귀식에서 나오지만 사용하는 정보가 다르므로 서로 직교에 가깝다.

- **RV** 는 회귀 잔차 ε 를 사용 — 시장 공통 변수와 직교적
- **MOM** 은 시장 공통 변수 dY_3Y 의 누적을 사용 — RV의 잔차와 무관
- **CURVE** 는 두 시장 변수의 차이(슬로프) 를 사용 — level 정보와 무관

이 구조적 분리 덕에 세 팩터의 일별 PnL 상관계수는 모두 0.3 미만으로 유지되며,
한 팩터를 다른 두 팩터로 회귀해 보아도 잔존 alpha 가 통계적으로 유의하게 남는다(특히 MOM 과 CURVE).

또한 잔차 ε 자체를 MOM/CURVE 신호로 회귀해도 거의 무상관(median |corr| < 0.03) 임이 확인되었다.
이는 RV 가 시장 공통 변수의 비선형 신호와도 독립적인 cross-sectional dislocation 만 잡고 있음을 의미한다.

세 팩터의 결합은 **시장 공통 risk(MOM, CURVE) + 종목 고유 risk(RV)** 의 자연스러운 분해다.
어느 한 팩터에 편중되지 않은 합성이 risk 측면에서도 분산 효과를 준다.

## 6. 신호 흐름 요약 (한 페이지)

```
[ 일일 데이터 ]
    dY_3Y,t, dY_10Y,t, 종목별 dY_i,t

        │
        ▼
┌──────────────────────────────┐
│ 2팩터 회귀 (3M rolling OLS)   │
│ dY_i = α + β3·dY_3 + β10·dY_10 + ε
└──────────────────────────────┘
        │
   ┌────┴────────────┐
   ▼                 ▼
[ε_i,t]         [dY_3Y, dY_10Y]
   │                 │
   ▼                 ▼

┌─────── RV ───────┐    ┌──── MOM ─────┐    ┌──── CURVE ────┐
```
